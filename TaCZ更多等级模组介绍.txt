================================================================================
《TaCZ 更多等级》模组介绍（详细版）
================================================================================
面向 Minecraft Forge 1.20.1，基于 Timeless and Classics Zero（TaCZ）。
核心玩法：防弹甲挡弹 → 枪械品质递进 → 士兵/Boss 阶梯 → 黑市经济 → 传说套装与传说武器。

数值以当前代码与默认 config/tacz_morelevel/armor.toml 为准，可热调。


================================================================================
〇、总览
================================================================================

主线                  内容
----                  ----
防弹成长              1～8 档防弹甲，对 TaCZ 子弹减伤 + 穿甲克制
枪械成长              改进→精致→完美→卓越 + Boss 传说枪
敌人阶梯              难民→民兵→雇佣兵→突击兵→特种→超特→Boss
经济                  黑市货币 + 1～5 级黑市联络系统
质变                  传说套技能键、夜视键、药品读条、护航

传说技能键：穿齐对应全套后按「盔甲传说技能」键触发（冲击波是按住蓄力/松开释放）。
夜视键：佩戴时空 / 动力机甲 / 特种作战 / 爆破七级 / 冲击波头盔时可开关。

依赖：TaCZ 枪包是武器底座；本模组负责甲、品质枪、NPC、经济与特殊道具。


================================================================================
一、按键与操作说明
================================================================================

模组在设置里单独一类：「TaCZ 更多等级」。
路径：设置 → 控制 → TaCZ 更多等级
开着 GUI（背包、聊天等）时模组专用键不会生效。


--------------------------------------------------------------------------------
1.1 模组专用按键（可改键）
--------------------------------------------------------------------------------

按键名              默认    作用
------              ----    ----
盔甲传说技能        X       触发当前穿戴全套对应的传说技能
盔甲夜视            O       开关盔甲夜视（需戴指定头盔）


--------------------------------------------------------------------------------
1.2 传说技能键（默认 X）——全套优先级
--------------------------------------------------------------------------------

同一时间只认一套（客户端按全套判定）：

优先顺序    全套            按键方式
--------    ----            --------
最高        冲击波套        按住蓄力 / 松开释放（不是点一下）
↓           爆破七级套      点按一次 → 召唤炸弹小车
↓           时空防弹套      点按一次（站立=记点，蹲下=回传）
↓           动力机甲全套    点按一次 → 过载

说明：
- 穿齐冲击波时，X 进入「按住模式」，不会再触发爆破/时空/过载。
- 非冲击波时：点一下发一个技能包；需满足全套 + 冷却/能量等条件才会成功。
- 军服「仆从的守卫」、小丑头「头部防御」、深渊/爆炎/幽匿等不用按 X（被动）。


--------------------------------------------------------------------------------
1.3 各套详细操作
--------------------------------------------------------------------------------

【冲击波套 — 按住 X】
按下 X      开始蓄力（能量→动能，播蓄力音）
按住不放    持续蓄力
松开 X      释放冲量，进入冲击态，撞物/人爆炸
能量耗尽    也会自动释放
冷却中      无法再蓄

【爆破七级 — 点 X】
点一下 → 身前召唤认主炸弹小车（CD 约 5 秒）

【时空套 — 点 X】
站立 + X          视线落点记存档（失败不覆盖旧点）
蹲下（Shift）+ X  回传到存档（成功才进约 5 秒 CD）

【动力机甲全套 — 点 X】
点一下 → 过载（需胸甲能量满 2000，一次扣光，给防护约 10 秒）


--------------------------------------------------------------------------------
1.4 夜视键（默认 O）
--------------------------------------------------------------------------------

操作：点按 O 开关
需要头盔：时空 / 动力机甲 / 特种作战 / 爆破七级 / 冲击波
成功：提示「夜视已开启 / 已关闭」
失败：提示需要佩戴上述头盔


--------------------------------------------------------------------------------
1.5 配合原版按键的系统
--------------------------------------------------------------------------------

【动力机甲飞行】
穿动力机甲胸甲 + 能量 > 0    允许飞行（生存/冒险）
双击空格                      进入/退出飞行（原版飞行手感）
不需要按 X                    飞行是被动系统；X 是全套过载

【药品读条】
按住右键    开始读条（绷带/急救包/医疗箱/针剂）
松开右键    打断；音效会停，效果不结算
读满结束    回血或上 buff，消耗物品

【投掷物】
手榴弹、燃烧瓶、探测手雷等：一般按住右键蓄力 → 松开扔出。

【时空之石（物品，不是套装键）】
站立 + 右键    视线落点闪现
蹲下 + 右键    随机闪现约 30～60 格
冷却           约 20 秒（物品冷却）

【护航】
护航联络器              右键方块 → 在落点召唤护航并认主
护航存储器（空）        右键己方护航 → 收纳
护航存储器（有货）      右键地面 → 放出

【黑市 / 方块】
黑市联络系统等：右键方块打开界面。

【枪械（TaCZ）】
射击、瞄准、换弹、切枪等走 TaCZ / 原版键位，本模组不另注册开枪键。
传说枪技能多为被动（命中减速、辅助瞄准等），一般不用额外键。


--------------------------------------------------------------------------------
1.6 操作速查表
--------------------------------------------------------------------------------

你想做的事          怎么按
----------          ------
冲击波冲撞          穿齐冲击波 → 按住 X 蓄力 → 松开
放炸弹小车          穿齐爆破七级 → 点 X
记时空点            穿齐时空 → 站立点 X
时空回传            穿齐时空 → 蹲下点 X
机甲过载            穿齐动力机甲 + 能量满 → 点 X
机甲飞行            穿动力胸甲有能量 → 双击空格
盔甲夜视            戴指定头盔 → 点 O
用药                按住右键读条
时空之石闪现        右键（站立视线 / 蹲下随机）
召唤护航            联络器右键方块
收/放护航           存储器右键实体 / 右键地面

改键与冲突：
- 若 X/O 和别的模组冲突，在控制设置里改掉即可。
- 冲击波与其它传说套不要指望同一键同时生效——冲击波全套时 X 只做蓄力释放。
- 打开背包时按 X/O 无效，先关掉界面。


================================================================================
二、防弹公式（所有套装共用底座）
================================================================================

--------------------------------------------------------------------------------
2.1 对 TaCZ 子弹的两套修正
--------------------------------------------------------------------------------

A. 子弹减伤（Bulletproof）
- 每件贡献 =「该档全套总和 ÷ 4」
- 四件累加：最终伤害 = 原伤害 × (1 − 减伤总和)
- 总和上限约 90%（armor.toml 可调）

B. 穿甲减免（Penetration Reduction）
- 从子弹字段 armorIgnore 上直接减去全套穿甲减免总和
- 减到负数按 0（子弹更「吃甲」）


--------------------------------------------------------------------------------
2.2 默认全套数值（档位 1～8）
--------------------------------------------------------------------------------

档    全套子弹减伤    全套穿甲减免    代表装备
--    ------------    ------------    --------
1     32%             10%             一级防弹
2     40%             20%             二级
3     48%             30%             三级
4     56%             40%             四级
5     64%             50%             五级
6     74%             60%             六级 / 特种作战（同档）
7     84%             72%             七级及多数传说变体
8     87%             80%             幽匿七级（特化）

单穿一件 = 上表 ÷ 4。混穿不同档按各件自己的档位相加。


--------------------------------------------------------------------------------
2.3 爆炸减伤（另一条轨）
--------------------------------------------------------------------------------

仅部分套装有，按「每件比例」叠加，与子弹减伤无关：

套装        默认每件    全套约
----        --------    ------
爆破七级    10%         40%
爆炎七级    20%         80%
动力机甲    8%          32%
特种作战    8%          32%
冲击波      8%          32%


--------------------------------------------------------------------------------
2.4 摔落减伤
--------------------------------------------------------------------------------

深渊 / 冲击波：默认每件 25%，四件可到约 100%（近似免疫摔落）。


--------------------------------------------------------------------------------
2.5 与其它减伤的结算关系
--------------------------------------------------------------------------------

自定义「防护」效果（Mod Defence）：伤害 ÷ (等级 + 1)，且优先于防弹减伤结算。
硬化针减伤走 LivingHurtEvent，与子弹防弹叠加时会进一步压扁枪伤——后期叠层很强。


================================================================================
三、武器：品质线 + 传说枪技能
================================================================================

--------------------------------------------------------------------------------
3.1 品质升级线
--------------------------------------------------------------------------------

用枪械升级凭证（改进绿 / 精致蓝 / 完美紫 / 卓越红）把原版 TaCZ 枪升到同名品质变体。
大量枪型都有四档（AKM、AUG、AA12、AWM、RPK、Vector、Type81、SCAR……）。
数值随品质抬升，仍走 TaCZ 弹道；传说枪不走这条凭证线，多来自 Boss / 特化。
另有超级升级模板等高级材料支撑后期合成。


--------------------------------------------------------------------------------
3.2 传说枪技能细表
--------------------------------------------------------------------------------

【HK-416D 歼灭者 — 辅助瞄准】
触发        手持该枪，命中目标后进入「记忆」
记忆        约 40 tick（2 秒），再次命中刷新
条件        目标存活；距离 ≤ 200 格；目标在准星射线旁 ≤ 1 格宽容区
行为        每 tick 把视角朝目标眼位拉近
拉枪步进    ≤12 格：每 tick 最多 1°；更远：12/距离 度
体验        打中后短暂「粘枪」，近距跟枪更狠，远距变弱

【M4_对掏天花板 — 头盔穿透】
定位        对掏天花板专武
数据侧      高穿甲（约 84% armor_ignore）、爆头倍率约 ×3、穿透 pierce=1
玩法含义    对头盔/头爆极其凶；配合小丑头「头部防御」形成攻防对位

【.22 943 型左轮传说 — 减速】
触发        该枪子弹命中（服务端）
概率        50%
效果        缓慢，可叠加，最高 III（显示等级）
时长        每次 2 秒（40 tick）
限制        不对自己生效

【M134 转管机枪传说】
超大弹容    弹匣约 1000
瞬间换弹    换弹 feed 时间极短（接近瞬填）
持续射击    高射速（约 1200 RPM）+ 大弹容支撑长时间压制
其它        不可匍匐射击配置；高穿甲约 90%

【RPG-7 火箭筒传说】
大幅加快换弹          数据向缩短装填
大幅降低拔枪时间      切枪/举枪更快，适合双持换枪流（战争机器主副手套路）

【爆破 MK14 — 子弹爆破】
核心        子弹带爆炸（直伤 + 溅射）
定位        炸弹宝宝主武器；打群与破防兼备
注意        爆炸伤与子弹直伤分轨，防爆甲主要吃溅射段

【连发榴弹炮（M320 传说）— 高爆榴弹】
定位        炸弹宝宝背枪；远距切榴弹
技能        高爆榴弹；Boss AI 会在视野/弹道条件满足时切枪抛物线射击

【AA12 冲击波】
定位        炸弹视野专武 + 冲击波套玩法
作用        霰弹火力与冲击波冲撞体系配套

--------------------------------------------------------------------------------
4.3 爆破七级套
--------------------------------------------------------------------------------

被动：爆炸防护 — 每件约 10%，全套约 40%。

主动传说：爆炸小车
条件        穿齐四件；不在冷却；非旁观
操作        按传说技能键（点 X）
冷却        5 秒（100 tick），记在胸甲 NBT
效果        身前约 1.2 格生成炸弹小车，认主
小车行为    追主人当前仇恨目标；距目标 ≤2 格自爆；爆炸半径约 7（可破方块）；
            寿命 TTL 约 200 tick 到期必爆；被打死有小爆炸（半径约 1.5）
友伤        同主小车互免；非玩家主人与车互免；玩家可打坏自己的车；
            爆炸不对主人造成伤害
Boss        炸弹宝宝用同一技能自动召唤
夜视        头盔可开（O）


--------------------------------------------------------------------------------
4.4 爆炎七级套
--------------------------------------------------------------------------------

爆炸防护    每件约 20%，全套约 80%（防榴弹/手雷极强）
抗火        穿戴刷新抗火（高等级，短周期续）
无主动键技能。


--------------------------------------------------------------------------------
4.5 深渊七级套
--------------------------------------------------------------------------------

速度提升    每件对移速基础段 +25%（MULTIPLY_BASE），四件约 +100%
跳跃        配套属性事件强化跳跃
摔落防护    每件约 25%，全套可近乎免疫摔落
无主动键技能。


--------------------------------------------------------------------------------
4.6 幽匿七级套
--------------------------------------------------------------------------------

极高防御    防弹档 8（全套约 87% 子弹减伤 + 80% 穿甲减免）
定位        纯对枪坦克，技能偏被动


--------------------------------------------------------------------------------
4.7 冲击波套
--------------------------------------------------------------------------------

被动：
- 防弹同七级
- 爆炸防护：全套约 32%
- 摔落防护：每件 25%
- 头盔夜视（O）

主动传说：冲击波（蓄力冲撞）
条件        穿齐四件；冷却结束
能量        胸甲能量池上限 2000；玩家每 tick 回 10
操作        按住传说键开始蓄力；松开释放；能量耗尽也会自动释放
冲量        impulse = 0.005 × kinetic
释放后      进入「冲击态」约 2 秒；撞到方块/生物时在贴合点爆炸
爆炸半径    按冲量映射，玩家约 2～10；炸弹视野 NPC 约 5～10
冷却        释放后约 2.5 秒（50 tick）
中断        松开/打断会停蓄力音


--------------------------------------------------------------------------------
4.8 动力机甲套
--------------------------------------------------------------------------------

被动：爆炸防护 — 全套约 32%。

飞行（胸甲系统，不必全套）：
条件        穿动力机甲胸甲；生存/冒险；能量 > 0
能量        上限 2000；飞行中约每 tick 耗 8×速度倍率；穿戴件数可回能
操作        双击空格进入原版飞行；HUD 显示能量
飞速        基础约 0.025，随能量比例变化
表现        飞行循环音、粒子、推进器动画；落地停音
创造/旁观不走机甲飞行逻辑。

主动传说：过载（需全套）
条件        四件齐；胸甲能量 ≥ 2000；非创造/旁观
消耗        一次性扣光 2000 能量
效果        获得自定义防护 II（显示），持续 10 秒
防护公式    伤害 ÷ (等级+1) → 防护 II 约为 伤害 ÷ 3
结算        先于防弹减伤，极肉
表现        过载专属音效/特效
战争机器 Boss 在低血+满能量时也会走类似过载/飞行逻辑。


--------------------------------------------------------------------------------
4.9 时空防弹套
--------------------------------------------------------------------------------

主动传说：空间移动（需全套）
站立 + 传说键    沿视线射线记存档点（维度+坐标）；落点须可站立；失败不覆盖旧点
蹲下 + 传说键    回传到存档点（可跨维）；成功才进冷却
回传冷却         5 秒（100 tick），只打在回传上，记点无 CD
失败提示         落点无效 / 无存档 / 维度不存在 / 存档不安全
夜视             头盔可开（O）

对照：时空之石（道具，不是套装技能）
站立右键    视线落点闪现
蹲下右键    随机闪现约 30～60 格
冷却        20 秒（400 tick）


--------------------------------------------------------------------------------
4.10 列夫元帅军服 — 仆从的守卫（被动）
--------------------------------------------------------------------------------

条件        穿齐军官制服四件
扫描        每 1 秒刷新一次
玩家        统计附近约水平 32 / 垂直 10 格内、认主自己的护航数 z
玩家防护    L = min(2z + 1, 5)（无护航则不给）

定位        「天花板的认证」；克制高爆头倍率传说枪

6.2 Boss 细表

【战争机器】

- 可穿动力机甲逻辑：飞行 / 低血满能时过载

- 传说左轮 943（命中减速叠加）
- 军官制服仆从的守卫（护卫数转防护）
- 伴随大帅护卫军

【歼灭者】
- 专武 HK-416D 歼灭者（辅助瞄准）
- 空间闪现：冷却就绪后可传送到目标附近/随机合法落点（禁水岩浆等）

【对掏天花板】
- 专武 M4_对掏（高穿甲/高爆头）
- 复杂机动技能机：侧向急蹲/急爬/跳蹲、猫步跳、瞬匍匐、错步、滑步等
- 头盔掉落率可单独配置（默认更高），掉小丑七级头

【炸弹宝宝】
- 装：爆破七级全套
- 主手爆破 MK14，背枪传奇 M320
- 抗性 III（约 80% 通用减伤）
- 技能：冷却到点召唤认主炸弹小车；远距可切榴弹弹道射击
- 自己人的小车不炸宝宝

【炸弹视野】
- AA12 冲击波 + 冲击波全套
- AI 使用冲击波蓄力冲撞（NPC 能量回复更快）

【炸弹小车】
- 见爆破套技能；也可作为独立中立单位

Boss 装备掉落常见约 20%（可配置）；护航单独击杀有时不算玩家击杀，可能影响装备掉落，建议自己补几枪。

八、推荐成长路径
================================================================================

1. 开荒：一级防弹 + 任意枪 → 刷难民/民兵
2. 成型：三级～四级甲 + 精致/完美枪 + 黑市 Lv1～2
3. 冲高：六～七级或特种作战；卓越枪；护航
4. 终局：按风格选传说套
   - 对枪坦克：幽匿 / 过载机甲
   - 机动：时空 / 深渊
   - 爆破图：爆炎 / 爆破小车
   - 冲撞节奏：冲击波 + AA12
5. Boss：带对应传说枪与克制甲（防爆打宝宝、小丑头抗对掏爆头等）
