# TaCZ 更多等级（Tacz More Level）

版本 1.4.3　·　Minecraft 1.20.1　·　Forge　·　作者作品

---

## 一句话

这是一个基于 Minecraft Java 版的游戏扩展模组。它建立在枪械模组 TaCZ 之上，给游戏补上一套完整的“枪战生存”内容：会持枪作战的敌对士兵、可穿戴的防弹装备、医疗与投掷道具，以及跟随玩家的护航同伴。

---

## 口头介绍（约两分钟）

老师好。我做的是 Minecraft 模组《TaCZ 更多等级》。

Minecraft 本身支持用 Java 编写模组，通过 Forge 加载进游戏。我的模组必须和枪械模组 TaCZ 一起运行，目标是在原版枪械系统外面，再做一层自己的玩法：敌人不只是原版僵尸，而是会拿枪、换弹、投掷手雷、根据距离移动的士兵；玩家则通过防弹衣、护甲板、药品和技能来对抗他们。

工程上，入口类 `Tacz_MoreLevel` 在游戏启动时向 Forge 注册实体、物品、方块、音效、粒子、网络协议和配置文件。敌人的行为没有写死在一个巨大函数里，而是拆成许多“目标”（Goal）：瞄准射击、切换武器、躲避手雷、匍匐、技能位移，由游戏每刻按优先级调度。装备上的传说技能走注册表，新技能按接口接入，不必改动总入口。数值放在独立的配置文件里（普通兵、首领、护甲分开），改平衡时不用重新编译。

目前模组大约有二十多种可战斗生物、多套分级防弹甲、插件工作台、黑市联络、限次刷怪和友方护航。客户端用 GeckoLib 播放三维装备动画，服务端负责伤害、弹道和实体逻辑，两边用自定义网络包同步。

## 模组解决什么问题

TaCZ 提供了枪、子弹和射击手感，但世界里几乎没有“会用这些枪”的对手，也没有和枪战匹配的防护与补给。本模组补的是这一层：

1. **对手。** 从民兵、难民、雇佣兵，到特种兵、超级特种兵，再到战争机器、歼灭者、毒蝎、炸弹宝宝等首领。
2. **防护。** 一至七级防弹套装，以及爆破、冲击波、辐射、潜行、时空、动力机甲等特殊套装。护甲可以插拔护甲板，在插件装备台上装配。
3. **补给与道具。** 手榴弹、闪光弹、燃烧瓶、探测雷、地雷、绷带、急救包、医疗箱、强化针。
4. **同伴。** 标准、高级、魔王等护航，以及军官制服召唤的护卫。它们站在玩家一边，使用同一套持枪战斗逻辑。
5. **世界设施。** 特种兵召唤方块、黑市联络系统、限次刷怪笼、无限网络接收器。

创意模式物品栏名称是「TaCZ 更多等级」。

## 程序是怎么组织的

代码包名是 `com.kkdfg.Tacz_morelevel`。启动类只做注册和公共初始化，具体玩法分在下面这些包里。

| 包 | 职责 |
| --- | --- |
| `entity` / `entity.custom` | 生物种类、属性、生成规则 |
| `entity.ai` | 战斗行为：射击、走位、换枪、手雷弹道、首领技能 |
| `entity.companion` | 友方护航与它们自己的行为 |
| `item` / `armor` | 物品、防弹衣、插板、传说技能 |
| `block` / `menu` | 方块、工作台界面与容器 |
| `network` | 客户端与服务端之间的数据包 |
| `config` | 普通兵、首领、护甲的可调数值 |
| `integration` | 和 TaCZ、卓越前线的对接；卓越前线未安装时跳过 |
| `client` / `dategen` | 按键、界面、粒子；配方、掉落、模型等数据生成 |

几处适合在课上讲的设计：

1. **注册表，而不是一长串 if。** 实体、物品、技能都先登记再使用。新增一种护甲技能时实现接口并 `register`，总入口不用知道每个技能的内部细节。
2. **行为拆成目标。** 例如炸弹宝宝的投掷单独是 `BombBabyGrenadeFireGoal`，弹道用带阻力和重力的离散模拟 `DiscreteDragGravityBallistics`，和“什么时候该扔”分开。换一个兵种可以复用弹道，只换决策。
3. **客户端与服务端分开。** 伤害、实体生成、技能是否允许发动以服务端为准；模型、动画、按键在客户端。避免“只在自己电脑上生效”的不同步。
4. **可选模组用兼容层。** `mods.toml` 里卓越前线是 `mandatory = false`。代码里检测到已加载才启用适配，单人只装 TaCZ 也能开服。
5. **数值外置。** `npc.toml`、`bosses.toml`、`armor.toml` 给服务器管理员改血量、伤害和护甲，不用改 Java 再打包。

## 和原版、和 TaCZ 的关系

- 原版 Minecraft 提供世界、实体、物品栏、合成和存档。
- Forge 提供模组加载、事件和注册表。
- TaCZ 提供枪械数据、射击和换弹。士兵手里的枪来自这套数据，本模组负责“谁来拿枪、何时开枪、打完怎么换武器”。
- 本模组的物品、生物 ID 都带前缀 `tacz_morelevel:`，不会覆盖原版或 TaCZ 的原有内容。

## 适合老师看的结论

这个项目不是改几个数值的资源包，而是一个用 Java 写的、有启动生命周期、注册表、人工智能行为、网络同步和配置系统的 Forge 模组。玩法上它把 TaCZ 的枪械变成可对抗的生存内容；工程上它把士兵、护甲技能和外部模组依赖拆开，方便继续加新兵种和新套装。

# 按独立游戏闭环看：现阶段各功能

如果把 Minecraft 和 TaCZ 看成已经提供的“引擎”（世界、移动、背包、枪械射击），本模组现阶段自己负责的是一条可重复的玩法环：

**遭遇敌人 → 用枪和道具打完 → 处理受伤和控制 → 拿到分层掉落 → 换成更强的枪、甲、药或同伴 → 再去打更高一档的敌人。**

世界探索、挖矿、原版进度仍然借 Minecraft。枪怎么发射、换弹、后坐力仍然借 TaCZ。下面只讲这条环上已经接上的功能，以及还没自己做成独立游戏的部分。

## 环怎么转

```text
投放战斗（刷怪 / 召唤方块 / 限次笼）
        ↓
战斗（持枪 AI、手雷、闪光、首领技能）
        ↓
生存（护甲、插板、读条药品、状态）
        ↓
掉落（货币位数、升级券、首领材料）
        ↓
转化（黑市、枪械四档、合成与锻造、护航）
        ↓
回到更高一档的战斗
```

低档兵掉低档货币和低档升级券，高档兵掉高档货币和高档券，首领掉专用材料。材料不是收藏品，而是下一套装备的配方。这是现阶段闭环能闭合的原因。

## 1. 投放：战斗从哪来

自然生成之外，有两个玩家可操作的关卡工具。

**限次刷怪笼。** 用刷怪蛋设定要刷的生物。它按冷却出怪，剩余次数存在方块里，次数用完就停。和平模式是否允许刷新可以单独看。独立游戏里这相当于“这一关还能打几次”，避免原版刷怪笼无限刷、奖励被刷穿。

**特种兵召唤方块。** 放入指定物品后，按数据包里的对照表在附近找空位，倒计时后召唤对应生物。投放表是 JSON，改“用什么换什么敌人”不用改 Java。独立游戏里这是用资源换一场指定战斗。

## 2. 战斗：敌人在环里的职责

敌人按掉落分成档，档位就是难度曲线。

| 档 | 生物 | 击杀掉落（概率写在战利品表里） |
| --- | --- | --- |
| 入门 | 难民、民兵 | 一位货币；改进级枪械升级券（难民约 5%，民兵约 10%） |
| 中段 | 雇佣兵 | 二位货币；精致级升级券 |
| 中高 | 突击兵、潜伏者 | 三位货币；完美级升级券 |
| 高段 | 特种兵、超级特种兵 | 四位货币；卓越级升级券（超特概率更高） |
| 首领材料 | 歼灭者、毒蝎、战争机器、炸弹视野、史莱姆指挥官、判罚者 | 见下一节，不走货币 |

战斗时这些生物共用一套持枪行为，再按兵种加自己的目标：瞄准射击、走位、双枪切换、躲避手雷、匍匐。手雷抛射用带阻力和重力的离散弹道，决定“何时扔”和“扔到哪”是分开的。

首领在同一套射击上再加身份：

- **战争机器**：飞行、换武器、火箭类火力。
- **歼灭者**：短距闪现。
- **毒蝎**：重狙加冲锋枪，交战中潜行。
- **炸弹宝宝**：爆破步枪加手榴弹。
- **炸弹视野**：冲击波霰弹，并使用和玩家同一套冲击波冲刺。
- **对掏天花板**：拉扯、爬行、跳跃等近身位移。
- **史莱姆指挥官**：分裂只产生战士，代数往下走。
- **判罚者**：不主动锁定玩家和友军。
- **列夫大帅**：带护卫军。

玩家侧的投掷物进入同一场战斗：手榴弹、闪光弹（玩家白屏，敌人被眩晕目标占住）、燃烧瓶、探测手雷、地雷、冰冻地雷。

## 3. 生存：挨打之后怎么回到环里

战斗会扣血、上控制。活下来靠三层，都要花时间或材料，不能无代价回满。

**护甲本体。** 防弹衣从一级到七级。七级以上不再只加防御，而是换玩法：时空、爆破、冲击波、潜行、动力机甲、军官制服等。特殊套多数要凑齐四件才开传说技能。

**插板。** 插件装备台把护甲板装进防弹衣，或拆下来。板分碳纤维、防弹钢、防爆钢、抗辐射，以及防闪光护目镜，各有初、中、高。板决定“抗哪一种伤害”，甲决定“哪一档能穿”。独立游戏里这是装备词条槽，不是再做一套新衣服。

**读条医疗。** 使用时不能瞬间回满，读条结束才结算：

| 药品 | 读条 | 效果 |
| --- | --- | --- |
| 绷带 | 2 秒 | 最大生命 10% 再加 2 点 |
| 急救包 | 3 秒 | 最大生命 50% 再加 4 点，并获得 3 秒生命恢复 |
| 医疗箱 | 4 秒 | 最大生命 75% 再加 5 点，并获得 5 秒生命恢复 |
| 硬化针 I / II / III | 3 秒 | 硬化 40 / 60 / 80 秒 |
| 综合免疫针 I / II / III | 3 秒 | 综合免疫 40 / 60 / 80 秒 |

硬化按等级减伤 10%、20%、30%，并降低移速，用机动换坦度。综合免疫每秒清一次不高于自身等级的中毒、凋零、虚弱、失明等负面效果。辐射是持续扣当前生命的负面状态，抗辐射板和免疫可以把它的有效等级压到零。

针剂配方把战斗掉落接回来：史莱姆指挥官掉血清；血清加注射器，再加下界之星得到硬化针，加龙蛋得到综合免疫针。数量 2、4、6 对应初、中、高。

## 4. 掉落：首领材料各自通向哪套装备

| 击败 | 掉落 | 用来做 |
| --- | --- | --- |
| 歼灭者 | 时空之石 1–3 | 时空防弹套；全套后可标记坐标并回传 |
| 毒蝎 | 吸光管 3–5 | 潜行七级套 |
| 战争机器 | 金色能量核心、金色动力推进器 | 动力机甲 |
| 炸弹视野 | 红色能量核心、红色动力推进器 | 冲击波套 |
| 史莱姆指挥官 | 粘液球、血清 4–7 | 硬化针、综合免疫针 |
| 判罚者 | 超级升级模板 1 个 | 锻造台把七级甲转成爆炎 / 深渊 / 幽匿七级 |

动力机甲全套可以飞行，飞行消耗胸甲能量，件数影响能量回复；过载再花一截能量换一段时间的伤害吸收，并提高爆炸减免。冲击波套按住蓄力、松开冲刺，和炸弹视野用的是同一技能。爆破七级全套可召唤认主的炸弹小车，冷却 5 秒。时空套站立标记、蹲下回传。潜行斗篷和潜行七级是开关式隐身。军官制服从胸甲储备里召出护卫，名册最多 4 个。

这些技能玩家按键触发，部分首领的 AI 走同一套激活入口。同一规则服务双方，后面做成独立游戏时不必为“玩家技能”和“怪物技能”各写一份。

## 5. 经济：货币和黑市

黑市通用货币分一位到四位。8 张低一级合成 1 张高一级，1 张高一级拆成 8 张低一级。兵种掉落的位数和难度对齐，所以打民兵攒起来的钱，和打特种兵直接掉的四位货币，是同一种资产的不同面额。

**黑市联络系统**分五级（白、绿、蓝、紫、红）。信标可以抬高这一级联络点能看到的市场等级。货单按级分开，有买入也有卖出，存在世界存档里。默认约每 10 分钟自动换一批；玩家也可以付材料手动刷新，已刷新次数会影响这次的花费。装了 JEI 时，买卖条目会出现在配方书里。

独立游戏里，黑市是环上的商店：战斗掉的货币在这里换成补给，卖出多余材料，而不是只在工作台里合成。

## 6. 枪械成长：四档升级券

TaCZ 的底枪可以被生成为四档衍生枪。升级券就是门票：

| 档 | 券 | 伤害倍率 | 操控相关倍率 |
| --- | --- | --- | --- |
| 改进 | 绿色 | 1.5 | 0.85 |
| 精致 | 蓝色 | 2.0 | 0.70 |
| 完美 | 紫色 | 2.5 | 0.55 |
| 卓越 | 红色 | 3.0 | 0.40 |

券从对应档位的士兵身上掉。低档战斗供给低档枪，高档战斗才供给卓越枪。生成器按底枪写出新的枪械数据包和合成，不把每把枪手写死。

## 7. 同伴：把战力从“自己”扩成小队

护航联络器分四档：美女、标准、高级、魔王。对方块使用后召唤，并绑定玩家为主人。护航用和敌兵同一类的持枪、匍匐、索敌逻辑，阵营相反。护卫仓储用来管理他们的装备。

军官制服则是另一条召唤：技能从胸甲里拿储备，召到身边，人数受名册限制。同伴死亡或换装都会把玩家再推回“补给—战斗”环，而不是召唤一只永久无敌的跟班。

## 8. 现阶段这条环已经闭合的部分，以及还借引擎的部分

已经能自己转起来的：

- 难度分档，且掉落位数、升级券档位跟着走。
- 首领材料有明确配方去向，打完能做成下一套能力。
- 受伤要用读条药和有副作用的针，不能白回血。
- 货币能合并、拆分，并在分级黑市里买卖、定时刷新。
- 关卡侧有限次笼和召唤方块，奖励不能无限刷。

还没有脱离 Minecraft / TaCZ、所以还不能称为独立游戏的：

- 地图、生存、合成界面仍是原版。
- 开枪、弹道手感、枪械数据包格式仍是 TaCZ。四档枪是在它上面生成的。
- 部分物品已有模型和注册，但还没进这条环。无限网络接收器、显示器、机箱目前主要是外观物品。炸弹宝宝的实体战利品表是空的，它的装备掉落走单独的槽位概率。
- 没有自己的关卡流程和胜负结算。限次笼和召唤方块是关卡工具，还不是一关接一关的战役。

给老师的说法可以收成一句：现阶段完成的是枪战生存的核心循环——战斗产出、治疗消耗、商店和装备把产出变强、再进入更高战斗；独立游戏还要替换掉的是世界和枪械这两层引擎，以及还没接上循环的展示用物品。
