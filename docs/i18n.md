# 多语言（i18n）说明

## 运行时语言（游戏加载）

路径：`src/main/resources/assets/tacz_morelevel/lang/`

| 文件 | 语言 |
|------|------|
| `zh_cn.json` | 简体中文 |
| `en_us.json` | 英语 |
| `zh_tw.json` | 繁体中文 |
| `ja_jp.json` | 日语 |
| `ko_kr.json` | 韩语 |
| `ru_ru.json` | 俄语 |
| `es_es.json` | 西班牙语（西班牙） |

缺键时客户端回退到 `en_us`。

## 翻译基线（防重复翻译）

路径：`docs/i18n/baseline/lang/`

这是**上次已定稿**的完整语言快照，**不参与游戏加载**。后续改文案时：

1. 以 `en_us` / `zh_cn` 为权威，改运行时 `assets/.../lang/`。
2. 与 `docs/i18n/baseline/lang/` **按 key 做 diff**，只译新增或变更的条目。
3. 定稿后把运行时各语言文件**回写覆盖** baseline，作为下一次的「上次内容」。

维护约定：键名与 `en_us` 一致；保留 `§` 格式码；专有名词风格统一。
