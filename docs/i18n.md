# 多语言（i18n）说明

> 模组资源路径：`src/main/resources/assets/tacz_morelevel/lang/`  
> 游戏内随客户端语言自动切换；缺键时回退到 `en_us`。

## 当前语言文件

| 文件 | 语言 | 说明 |
|------|------|------|
| `zh_cn.json` | 简体中文 | 主语言（原文） |
| `en_us.json` | 英语（美国） | 国际默认 / 键模板 |
| `zh_tw.json` | 繁体中文 | 由简中转繁，港台用词取向 |
| `ja_jp.json` | 日语 | 对照英/中译出 |
| `ko_kr.json` | 韩语 | 对照英/中译出 |
| `ru_ru.json` | 俄语 | 对照英/中译出 |
| `es_es.json` | 西班牙语（西班牙） | 对照英/中译出 |

各文件键数量应与 `en_us.json` 一致（当前约 **971** 条）。

## 维护约定

1. **以 `en_us.json` 为键权威**：新增或重命名翻译键时，先改 `en_us`（及 `zh_cn`），再同步其它语言。
2. **不要改键名**：只改 JSON 的 value；键必须全局一致。
3. **保留格式码**：`§a`、`§l`、`§o`、`§r` 等 Minecraft 样式码位置与数量不要丢。
4. **专有名词**：`TaCZ`、Boss / 枪械型号名等可保留拉丁原文或沿用既有音译，各语言保持风格一致。
5. **未完成语言**：宁可暂不提交该文件，也不要提交缺大量键的半成品。

## 与 TaCZ 的对齐

默认枪包（`tacz_default_gun`）已常见：`zh_cn` / `zh_tw` / `ja_jp` / `ko_kr` / `ru_ru` / `es_es` 等。  
本模组本批优先补齐与上述重叠的高需求语言，便于整合包玩家语言环境一致。

## 后续可扩展（未做）

按需再加，例如：`de_de`、`fr_fr`、`pt_br`、`pl_pl`、`uk_ua`、`vi_vn`、`th_th`、`id_id`、`it_it` 等。

## 自检（可选）

在项目根用 Python 核对键集合是否与英语一致：

```python
import json
from pathlib import Path
lang = Path("src/main/resources/assets/tacz_morelevel/lang")
en = set(json.loads((lang / "en_us.json").read_text(encoding="utf-8")))
for p in sorted(lang.glob("*.json")):
    keys = set(json.loads(p.read_text(encoding="utf-8")))
    print(p.name, len(keys), "missing", len(en - keys), "extra", len(keys - en))
```
